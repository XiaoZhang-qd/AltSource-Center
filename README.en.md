# AltSource Center

A C11-first, local-first AltSource browser for iPhone/iPad.

Web: https://xiaozhang-qd.github.io/AltSource-Center/web/

Releases: https://github.com/XiaoZhang-qd/AltSource-Center/releases

Supports source management, app search, app details, IPA URL copying, sideloader URL schemes, local import/export, themes and multilingual UI.

This is a URL catalog/launcher, not a signing engine. Signing and installation are performed by the selected sideloader.
