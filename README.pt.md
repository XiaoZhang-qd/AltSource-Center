# AltSource Center

Um navegador AltSource local-first baseado em C11.

Web: https://xiaozhang-qd.github.io/AltSource-Center/web/

Releases: https://github.com/XiaoZhang-qd/AltSource-Center/releases

Gestão de fontes, pesquisa de apps, URL de IPA, protocolos de sideloading, temas e vários idiomas.
