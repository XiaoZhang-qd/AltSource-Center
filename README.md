# AltSource Center

C11-first、local-first 的 AltSource 浏览器，面向 iPhone/iPad，并提供 Web 版。

- Web：https://xiaozhang-qd.github.io/AltSource-Center/web/
- GitHub Releases：https://github.com/XiaoZhang-qd/AltSource-Center/releases
- 支持软件源管理、应用搜索、应用详情、IPA URL、侧载工具 URL 协议
- 支持本地导入/导出、浅色/深色/跟随系统主题、多语言

本项目是 URL 启动器/软件目录，不是签名引擎；实际签名和安装由所选侧载工具负责。
