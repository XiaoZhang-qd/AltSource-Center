# AltSource Center

Локальный AltSource-браузер на базе C11.

Web: https://xiaozhang-qd.github.io/AltSource-Center/web/

Releases: https://github.com/XiaoZhang-qd/AltSource-Center/releases

Поддерживает управление источниками, поиск приложений, детали, IPA URL, протоколы sideloading, темы и несколько языков.
