# URL handlers

Handlers are configuration-driven so new sideloading clients can be added without redesigning the catalog.

## Source

```text
altstore-classic://source?url=...
sidestore://source?url=...
feather://source/...
livecontainer://sources?url=...
stikstore://add-source?url=...
trollapps://add?url=...
flarestore://source?url=...
esign://addsource?url=...
ksign://addsource?url=...
gbox://AddSource/...
kravasigner://addRepo=...
```

## IPA

Only clients with documented install actions are exposed in **Get**:

```text
altstore://install?url=...
sidestore://install?url=...
feather://install/...
esign://install?url=...
ksign://install?url=...
```

Edit `src/resources/url_handlers.json` and the mirrored web handler list when adding a new client.
